% \subsection{Evaluation design and rationale}
% We evaluate the system under test (SUT) --- a sub-1B on-device assistant --- not with
% human participants but with a fixed library of \emph{scripted} synthetic users. Two
% considerations drive this choice. First, recruiting human users to probe a model for
% trust failures (fabrication, sycophancy, mishandled distress) raises ethical-review
% burden disproportionate to a Master's-timescale study, and exposes participants to a
% deliberately under-resourced model. Second, and decisively for a methods contribution,
% scripted users make the evaluation \emph{reproducible}: every user turn is fixed text,
% replayed verbatim, so a run can be repeated exactly and a behavioural change attributed
% to the model rather than to drift in how the user was simulated.
%
% We separate three roles that an LLM could otherwise blur together: the SUT, the
% \emph{user simulation}, and the \emph{assessor}. A known risk of LLM-driven evaluation
% is that nondeterminism in any of the three confounds the measurement. We remove the
% largest source by making the user simulation \emph{non-generative}: it is a hand-written
% script, not an LLM. Only the assessor remains an LLM, and we pin it (Section~\ref{sec:repro}).
%
% \subsection{The assessor: a two-tier, literature-grounded design}
% Assessment is two-tier. The first tier is a \emph{deterministic, rule-based} assessor:
% regular-expression and tool-trace checks that score each response against a single
% constitutional principle (e.g.\ "did the model call \texttt{python\_execute} for this
% arithmetic?"). These are exact and reproducible and form the primary signal. The second
% tier is an \emph{LLM assessor} that scores semantic qualities the rules cannot capture
% (empathy, personalisation, coherence across turns).
%
% Using an LLM as assessor is now an established practice: \citet{zheng2023judgingllmasajudgemtbenchchatbot}
% show that a strong LLM judge agrees with human preferences at rates comparable to human
% inter-annotator agreement on open-ended responses, which is the regime our conversational
% trust dimensions occupy. We adopt three safeguards that the same literature motivates and
% that our supervisor emphasised. (i) \textbf{Different model family.} The assessor is drawn
% from a different model family than the SUT (a frontier model judging a Qwen-derived 0.6B),
% so the judge does not simply reward its own stylistic priors. (ii) \textbf{Rules as anchor.}
% Wherever a principle is rule-checkable, the deterministic score is reported alongside, and
% takes precedence over, the LLM score --- the LLM never silently overrides a verifiable fact.
% (iii) \textbf{Excluded, not floored, on failure.} A malformed or failed judge call is
% recorded as missing and excluded from the average, never imputed to a mid-scale value, so a
% judge that did not actually run cannot inflate or deflate a result.
%
% The constitutional framing of the SUT follows \citet{bai2022constitutionalaiharmlessnessai};
% its viability and limits at sub-1B scale are exactly what we measure, and prior small-model
% studies report mixed results \citep{menke2025effectiveconstitutionalaismall,
% zhang2025constitutioncollapseexploringconstitutional}, which our ablation is designed to
% quantify rather than assume.
%
% \subsection{Metric design and the redundancy check}
% The LLM assessor scores each whole conversation on six dimensions --- personalisation,
% memory consistency, empathy, trustworthiness, coherence, and goal completion --- each with
% an explicit 0--1 anchored rubric rather than an unlabelled scale, since coarse anchors
% reduce the scale-point ambiguity that degrades LLM scoring consistency. Crafting and
% validating the rubric itself follows constitution-evaluation practice
% \citep{kyrychenko2025c3aicraftingevaluatingconstitutions}.
%
% A multi-dimensional rubric risks \emph{overlapping} metrics whose scores move together and
% therefore compound rather than inform. We treat this as an empirical question, not an
% assumption: we report the per-dimension scores as primary (the aggregate "overall" is
% illustrative only), and we compute the Pearson correlation between every pair of dimensions,
% pooled across all conditions and personas. Any distinct pair with $|r|\ge 0.9$ is flagged as
% near-redundant and is a candidate to merge or re-define before the dimension is used as
% evidence. (This matrix is produced automatically by \texttt{analyze\_experiments.py}.)
%
% \subsection{Experimental conditions: a five-rung ablation ladder}
% \label{sec:ladder}
% The headline comparison is a five-rung ladder in which each adjacent step changes exactly
% one factor, so each \emph{delta} isolates one contribution:
% \begin{enumerate}
%   \item \textbf{C0} vanilla base, tools disabled --- the parametric floor.
%   \item \textbf{C1} vanilla base, tools enabled. $\Delta(\text{C1}-\text{C0})$ = value of tool access alone.
%   \item \textbf{C2} template-SFT (Experiment 1). $\Delta(\text{C2}-\text{C1})$ = value of SFT formatting.
%   \item \textbf{C3} constitutional-SFT (Experiment 2). $\Delta(\text{C3}-\text{C2})$ = value of constitutional content.
%   \item \textbf{C4} Thinker--Executor dual-SFT (Experiment 3). $\Delta(\text{C4}-\text{C3})$ = value of the architecture.
% \end{enumerate}
% All five are served through one inference interface and evaluated by the identical suites,
% so the reports share one schema and pair directly. We note one residual confound: C2 and C3
% differ in training content \emph{and} system prompt and tool inventory, so $\Delta(\text{C3}-\text{C2})$
% is read as "constitutional vs template SFT", not a single-variable isolation.
%
% \subsection{Statistical treatment}
% The probe sets are deliberately small (tens of items per suite, seven personas), so we
% report uncertainty rather than bare point estimates. For each isolating delta we give a
% bootstrap 95\% confidence interval over items; for paired pass/fail comparisons on the same
% probes across adjacent rungs we use McNemar's test. Per-dimension persona scores are
% reported with their spread across personas and interpreted cautiously given $n=7$.
%
% \subsection{Reproducibility protocol}
% \label{sec:repro}
% Reproducibility is engineered in, following Owen's guidance that the design effort sits in
% the \emph{guidelines} (the fixed scripts and rubrics), not in per-run engineering: change a
% guideline and the run changes predictably; leave it fixed and the run repeats. Concretely:
% (i) model decoding is greedy (\texttt{temperature}=0); (ii) the user side is fully scripted;
% (iii) the assessor model and version are fixed across all conditions and recorded in each
% report's \texttt{run\_metadata.judged\_by}; (iv) generation and judging are separate stages,
% so re-scoring with a different assessor never requires re-running the model; (v) every
% scored item carries its own principle and rubric in the saved report, making each report
% self-describing and auditable. The one input we do not freeze is live web search: tool-using
% probes call a real search provider, so the handful of web-grounded items reflect the live web
% and are not byte-reproducible across runs (a fixed-corpus mode exists for exact replication
% when required).
%
% \subsection{Threats to validity}
% The main threat is assessor circularity, mitigated by the rule-based anchor and the
% cross-family judge above. Small sample sizes limit statistical power; we therefore lead with
% effect sizes and intervals, not significance alone. Live web search makes the few web-grounded
% probes non-deterministic; we treat those items as a current-events spot-check rather than a
% reproducible metric, and rely on the offline alignment metrics for grounded-fabrication
% evidence. The persona library, though spanning distinct user types (including a deliberately
% error-prone "incompetent" user), is not a representative population, and any external survey we
% cite for motivation should be read with its own demographic scope in mind (e.g.\ US-centric
% trust surveys).

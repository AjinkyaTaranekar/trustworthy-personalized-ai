# 2026-05-03: Research Question Reframe

**The thesis gains a concrete, falsifiable empirical claim: a 0.6B on-device model, trained with constitution-guided SFT and GRPO, can achieve trust and empathy ratings comparable to frontier API models on targeted behaviours while providing a qualitatively superior privacy guarantee through local deployment.**

---

## What changed

During a session on 2026-05-03, a critical gap in the project was surfaced: the SFT pipeline uses an LLM to generate training data for another LLM, which is circular distillation unless there is an external human-judgment ground truth. Additionally, the thesis lacked a concrete comparison target — it claimed a modular small model is "more trustworthy" than a monolithic large model without specifying what "more trustworthy" means or whom it is compared against.

The reframe adds three things:

1. **Psychological grounding for the constitution** — each of the 19 principles is now mapped to a peer-reviewed construct from trust theory, metacognition, or conversational theory. See [[topics/constitution-psychological-grounding]].

2. **Human evaluation rubric** — a 12-item Likert instrument based on Mayer et al. (1995) and Davis (1983), providing an independent ground truth that is not derived from any LLM. See [[experiments/human-evaluation-rubric]].

3. **Frontier model comparison** — a formal study comparing untuned Qwen3-0.6B, fine-tuned Qwen3-0.6B, Claude Sonnet 4.6, Minimax M2.7, and Kimi K2.6 across 50 prompts evaluated by both automated constitution compliance scoring and human raters. See [[experiments/frontier-model-comparison]].

---

## Compatibility with the original research question

The original research question (from `researchplan.tex`, unchanged) is:

> "How can we architect a modular conversational AI system that prioritises transparency and is capable of genuine contextual empathy through systematic User Modelling and appropriate tool delegation, rather than relying solely on end-to-end neural generation?"

The reframe does not replace this. It adds an operational hypothesis to accompany it:

> **Operational hypothesis**: A 0.6B model fine-tuned with constitution-guided SFT and GRPO achieves trust and empathy ratings comparable to frontier models (within 0.5 points on a 5-point scale) on targeted trust-relevant behaviours, while running entirely on-device with local user memory and no persistent internet access — offering a privacy guarantee that API-only frontier models cannot match by architectural necessity.

The original question is about *how to build the architecture*. The operational hypothesis is about *what that architecture achieves in measurable terms*. Both are needed for a complete thesis.

---

## Why the comparison is not "can we beat Claude"

Frontier models will almost certainly outperform a 0.6B model on raw capability. That is not the claim. The claim is:

- On **specific, constitution-targeted behaviours** (honest refusal, uncertainty quantification, resisting pressure, one-question-at-a-time clarification), a fine-tuned small model can be *functionally comparable* to much larger models.
- On **privacy**, a local model is categorically superior — no user message leaves the device.
- On **user memory and empathy**, local computation means the user's psychological profile never touches a third-party server. This is the thesis's distinctive contribution relative to Anthropic's memory feature, OpenAI's memory, or Google's personalisation — all of which require server-side storage.

---

## The distillation problem — how it is resolved

The concern: if a teacher LLM generates training data, the student merely distills the teacher's biases. This is valid. The resolution has two parts:

1. **The constitution is not generated by the teacher.** The 19 principles are grounded in independent human values literature (see [[topics/constitution-psychological-grounding]]). The teacher model is used only to express those principles in natural language examples — the principles themselves come from outside the model.

2. **Evaluation is external.** The human evaluation rubric provides a ground truth that neither the teacher nor the student model can influence. If the student scores well on human trust ratings, the pipeline is validated regardless of who wrote the training data.

This is structurally analogous to Constitutional AI (Bai et al. 2022 — [[sources/papers/constitutional-ai-bai]]): a constitution grounded in human values + AI-assisted scaling + human evaluation. The difference in this project is scale (0.6B not 8B) and deployment target (on-device not API).

---

## Decisions made

- The 50-prompt evaluation set will be fixed before the GPU training run, so it cannot be contaminated by training data.
- Human evaluators will be recruited from TCD (students / staff) who are naive to the project.
- Model identity will be blinded during human evaluation.
- Frontier model API identifiers (Minimax M2.7, Kimi K2.6) must be verified against current API documentation before the study runs — the model names were proposed by the student but may not match the exact API strings.
